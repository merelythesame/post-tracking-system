TrackingDetails

(require("TrackingDetails"))(props) → {JSX.Element}

Description:

  • Displays full tracking details for a given shipment, including current status, send/arrive timestamps, sending branch, current location, and receiving branch information.

Source:
  • TrackingDetails.jsx, line 59
Example
<TrackingDetails
  shipment={{ id: 1, sendOffice: 2, receiveOffice: 5 }}
  trackingStatuses={[
    { shipment_id: 1, status: "In Transit", location: "Kyiv Hub",
      sendAt: 1710000000, arriveAt: 1710100000,
      send_at: "2024-03-10", arrive_at: "2024-03-11" }
  ]}
  postOffices={[
    { id: 2, name: "Kyiv Central", address: "Khreshchatyk 1", city: "Kyiv", postalCode: "01001" },
    { id: 5, name: "Lviv Main", address: "Rynok Square 5", city: "Lviv", postalCode: "79000" }
  ]}
/>
